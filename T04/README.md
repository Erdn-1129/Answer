# 整体思路

## 启动方式

### 本地服务器

因为图表需要从CSV文件读取数据，而浏览器出于安全策略会拦截 `file://` 协议下的本地文件读取（即CORS限制），所以不能直接双击 `index.html` 打开，必须启动一个本地服务器。步骤如下：

1. 打开终端，进入项目目录：

   ```bash
   cd ~/Answer/T04
   ```

2. 启动 Python 自带的轻量服务器：

   ```bash
   python3 -m http.server 8791
   ```

3. 在浏览器地址栏输入 `http://127.0.0.1:8791/build/index.html` 即可查看图表。

4. 使用完毕后，在终端按`Ctrl+C`停止服务器。

### VS Code

这个方法更简单了，如果你有vscode，直接用vscode的浏览器加载`index.html`就能正常显示

### 文件结构

这个项目共五个文件

- `build/index.html`：页面文档本身，定义网页结构，并内嵌一块 `<svg id="chart">` 画布作为图形容器。
- `src/style.css`：样式表，控制字体、画布最大宽度、文字不可选中等外观细节。
- `src/chart.js`：核心脚本，用 D3 工具库计算几何坐标并逐层绘制图形。
- `src/DataSet.csv`：原始数据表，包含 50 家公司、5 个岗位指标的数值。
- `src/vendor/d3.v7.min.js`：D3 第 7 版工具库，离线可用。

运行链条是：浏览器解析 `index.html` → 按顺序加载 `d3.v7.min.js`（失败则回退 CDN）→ 执行 `chart.js` → `chart.js` 通过 `d3.csv` 读取 `DataSet.csv` → 依据数据把图形画进 `<svg>`。

### index.html 的文档结构与画布定义

`index.html` 头部用 `<meta charset="UTF-8">` 保证中文不乱码，用 `<link>` 引入 `style.css`。主体 `<body>` 中只有一块 `<svg>`：

```html
<svg id="chart" viewBox="0 40 900 680"
     preserveAspectRatio="xMidYMid meet"
     style="width:100%;height:auto;display:block"></svg>
```

关键点在于 `viewBox="0 40 900 680"`：它定义了一个内部坐标系，从点 (0,40) 起，可见范围宽 900、高 680。所有图形的坐标都按这个范围书写，与实际屏幕像素解耦；配合 `width:100%`，画布会随容器自动缩放且不变形，达到一个响应式的效果。`id="chart"` 则是 JS 后续定位这块画布的锚点。

随后四个 `<script>` 依次加载：本地 D3、CDN 兜底、D3 缺失时的红色提示、最后才是 `chart.js`。顺序不能颠倒——`chart.js` 依赖 D3，必须先有工具库再执行绘图。

### style.css 控制外观

内容很短：设定字体栈（system-ui / PingFang SC / Microsoft YaHei）让中英文清晰；`svg { max-width:1000px }` 限制画布最大宽度；`svg text { user-select:none }` 禁止选中图上文字。这部分基本无需改动。

### chart.js 的几何地基

`chart.js` 全程约 167 行，可分成五段。

**第一段，确定全局参数（第 4–9 行）：**

```js
const cx=450, cy=425, R=300;
const axisMax=20, bandCount=10;
const colors = d3.range(10).map(i => d3.interpolatePurples(0.15 + i*0.07));
```

中心 `O=(450,425)`，外接圆半径 `R=300` 决定图的整体尺寸；数值量程 `axisMax=20` 与层数 `bandCount=10` 共同决定最大可表示 200；`colors` 用 D3 紫色插值生成 10 个由浅到深的色阶，浅色代表低层数值、深色代表高层数值。

**第二段，计算五边形顶点（第 11–18 行）：** 五个顶点角度写死（B:54°、A:-18°、C:-90°、D:-162°、E:126°，即 72° 均分一圈），每个角度转弧度后用 `cos` 算 x、`sin` 算 y（注意 SVG 的 y 轴向下），得到屏幕坐标存入 `vertices` 对象，如 `vertices.B`。

**第三段，定义扇区（第 21–27 行）：** `systems` 数组列出 5 个扇区，每个形如 `{ xEnd:"B", yStart:"B", yEnd:"A", column:"SoftwareEngineer" }`，即三角形 `O-B-A`。五个三角形绕中心一圈恰好拼成五边形。

**第四段，坐标变换核心 `toScreen`（第 116–119 行）：**

```js
const toScreen = (lx, ly) => ({
  x: O.x + xV.x*lx + yV.x*(ly/axisMax),
  y: O.y + xV.y*lx + yV.y*(ly/axisMax)
});
```

它以半径方向向量 `xV`（O→顶点）和底边方向向量 `yV` 为基，把沿半径位置 `lx`（0 在中心、1 在顶点）与数值 `ly`线性组合成屏幕坐标。这是全部几何的数学发动机。

### chart.js 的静态骨架

在读取数据之前，代码先用 `el()` 辅助函数批量绘制不依赖数据的框架。`el()` 是一个生成元素的快捷键：

```js
const el = (tag, attrs) => {
  const sel = svg.append(tag);
  for (const k in attrs) sel.attr(k, attrs[k]);
  return sel;
};
```

传入标签名与属性对象，内部循环调用 D3 的 `append`/`attr` 逐个设属性。这里必须用循环，因为 D3 v7 中 `sel.attr({...})` 的对象写法不是赋值器，会返回 `null` 导致报错

外五边形边框（`polygon`，五个顶点连成）；每个扇区的 X 轴（O→顶点的半径线）与 Y 轴（底边线）；在底边上用底边向量旋转 90° 得到法向 `nx,ny`的方法，画出垂直于轴的刻度短线及 0/4/8/12/16/20 的数值（第 49–61 行，`t=v/20` 把数值线性映射到底边位置）；中心白点；按顶点方位自动选左/中/右对齐的五个岗位标签（第 68–77 行）；左上角图例（10 个 `colors[i]` 色块加区间文字 1–20、21–40…）。

### chart.js 的动态数据层

`d3.csv("../src/DataSet.csv").then(data => { ... })` 读取数据后，先做一次体检（第 98–103 行）：把所有数值摊平，用 `console.warn` 提示无法解析的项（会产生空洞）和超过 200 的项（超出量程）。随后对每个扇区执行三步。

**第一步，类正态排列（第 108–111 行）：** 先按该列数值升序排序，再从两端向中间交替填充——最小的放 `x=0` 与 `x=1` 两头，最大的挤在 `x≈0.5` 中间。结果沿半径方向形成中间高、两边低的钟形分布。

**第二步，地平线折叠叠加（第 123–138 行）**

```js
for (let layer=0; layer<10; layer++){
  const lower=layer*20, upper=lower+20;
  const pts = rows.map((row,i)=>{
    const v=Number(row[col]);
    const x=i/(rows.length-1);
    let fill=0;
    if(v>lower) fill=(Math.min(v,upper)-lower)/20;
    return { x, y: fill*(20*x) };
  });
  el("polygon", { points: poly.join(" "), fill: colors[layer], opacity:0.55 });
}
```

外层循环0到9共10层，每层只负责一段20的数值区间（第0层0–20、第1层20–40……第9层 180–200）。对每一层遍历 50 家公司，算出该值落在本层的占比 `fill`（0到1），写成 `{x, y: fill*(20*x)}`。其中 `×x` 是三角形裁剪：离中心越近（`x` 越小）可用高度越小，整体因此被压成三角形。每层绘制一个半透明（`opacity:0.55`）多边形，10 层叠加后颜色自然融合。浅色贴着 X 轴（低层）、深色浮在外层（高层），颜色深浅与叠加层数共同编码数值大小，而图形总高度被压缩进一个三角形

**第三步，坐标映射与闭合：** 每个扇区算好 `xV`、`yV` 后，`toScreen` 把每列局部坐标转成屏幕坐标，再把各列顶部点顺次连成多边形，并沿基线绕回闭合，得到该层的彩色形状。五个扇区重复此过程，分别填充五个三角区域。

---

### 均值雷达

所有扇区绘制完成后，叠加一条均值雷达（第 142–159 行）：每个扇区用 `d3.mean` 计算该指标平均值，沿各自半径方向放置在平均值/200 × R处，五个点连成一条无填充的橙色线框（`stroke:"#ffab3d"`），再补圆点与均值数字。它作为各指标平均水平的轮廓叠在彩色色带之上，便于横向比较五个岗位的整体量级。

---

整体来看，`chart.js` 以固定顶点算出五边形与 5 个三角扇区，用 `toScreen` 把位置+数值映射为屏幕坐标，分 10 层把数值折叠成由浅到深的叠加色带、靠 `×x` 裁成三角形，再用从两头往中间填排成钟形脊线，最后叠一条橙色均值线框；约 167 行，数百个图形元素全部依赖 `el()` 快捷键批量生成，几何、骨架、数据、雷达四段层层递进，构成完整的可视化实现。
